你是一名资深计算机视觉/深度学习工程师。请在我提供的基础项目上完成“机器人肖像绘制艺术风格学习（L1）”课程任务。

【总目标】
实现一个可复现的端到端系统：
1. 输入单张人脸照片；
2. 生成艺术肖像线稿/绘画风格图；
3. 对眼睛、眉毛、鼻子、嘴巴、脸部轮廓、头发等局部结构尽量保持身份与几何一致性；
4. 将最终线稿矢量化为 SVG；
5. 输出定量评价与可视化对比；
6. 支持扩展到动漫/卡通风格。

【必须遵守】
- 不要从零重写 APDrawingGAN；优先把官方仓库作为 third_party 外部依赖，通过 adapter 调用。
- 官方 APDrawingGAN 代码较旧，因此主项目使用现代 Python 环境，legacy 模型放独立环境；不要强行把所有依赖混在一个 requirements.txt。
- 不要虚构模型权重、数据路径或实验结果。缺少权重/数据时给出明确下载/放置说明。
- 任何脚本都必须有 argparse、清晰报错、相对路径支持。
- 训练/测试必须固定随机种子并记录配置。
- 代码要能在没有 GPU 时至少跑通 baseline + SVG + metrics。
- 对第三方代码只做最小侵入适配，并保留许可证/引用。

【参考路线】
A. 主线：APDrawingGAN / APDrawingGAN++ 做照片->艺术肖像线稿。
B. 基线：项目内 OpenCV line-art，确保端到端可运行。
C. 扩展：U-GAT-IT 或 GANs N' Roses 做卡通/动漫风格（作为扩展实验，不替代主线）。
D. 矢量化：对二值/灰度线稿做轮廓提取、曲线简化，输出 SVG。
E. 评价：
   - SSIM：结构相似度；
   - Edge-F1：边缘/线条一致性；
   - LPIPS：感知距离（可选依赖，越低越好）；
   - SVG path_count/file_size：矢量复杂度；
   - 人工局部评分表：eyes / eyebrows / nose / mouth / contour / hair，各 1~5 分。
